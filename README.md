# 学航助手 · 小学生学习规划管理系统

🌐 在线访问：https://fuzzylogic112.github.io/study-planner/

一款为小学生家庭设计的**学习规划管理**单页应用：作业管理、专注计时、习惯打卡、课程表、错题本、积分激励、成长报告，一个页面全搞定。

## 功能一览

| 模块 | 说明 |
|---|---|
| 🏠 首页仪表盘 | 按时段问候；今日作业进度环、今日专注时长、积分余额、今日课程、待复习错题；近 7 天专注趋势图；每日一条教育建议 |
| 📝 作业管理 | 按学科 / 来源 / 状态三维筛选，按日期分组；计划用时 vs 实际用时（⚡）；专注计时器：倒计时、暂停 / 继续、完成 / 放弃，全局悬浮计时条，刷新不丢失 |
| ⏱️ 专注打卡 | 习惯 + 学科打卡计划，计时类 / 直接完成类，完成后即时加分 |
| 📅 课程表 | 周视图，左右切周，节假日标注；线上 / 线下、老师、地点、可回放、停课状态一目了然 |
| ❌ 错题本 | 按学科记录错题（题目 / 错误原因 / 正确思路 / 掌握度星级），艾宾浩斯 1 / 2 / 4 / 7 / 15 / 30 天自动安排复习 |
| ⭐ 积分中心 | 积分规则、明细流水、奖励兑换（家长可自定义奖励） |
| 📈 成长报告 | 本周作业完成率、专注时长趋势、学科时间分布、积分趋势，鼓励性语言总结 |
| ⚙️ 设置 | 学生信息、数据导出 / 导入 / 清空 |

## 教育理念

- **目标 - 计划 - 执行 - 复盘** 完整闭环
- **正向激励为主**：完成即时加分 + 鼓励语
- **番茄钟**专注法（默认 25 分钟，可调）
- **艾宾浩斯遗忘曲线**科学安排错题复习

## 使用说明

1. 用浏览器打开上方在线地址即可使用（手机 / 电脑均可）。
2. 数据保存在**本机浏览器**中，刷新、关闭都不丢失。
3. 换设备使用时：旧设备「设置 → 导出数据」得到 JSON 文件，新设备「设置 → 导入数据」即可衔接。
4. 首次打开内置演示数据，替换成自己家的真实安排即可正式使用。

## 技术

- 单文件 `index.html`，原生 HTML / CSS / JavaScript，**零外部依赖**，离线可打开
- 数据经 localStorage 版本化持久化（`xuehang_db_v1`），支持版本迁移
- 响应式布局，桌面端优先，兼容手机宽度
