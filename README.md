# 学航助手 · 全学段学习规划

🌐 在线访问：https://fuzzylogic112.github.io/study-planner/

一款覆盖**小学 → 初中 → 高中 → 大学 → 考研 → 考公考编**全学段的学习规划与辅导工具：目标管理、任务规划、专注计时、习惯打卡、课程表、复习中心、自测组卷、考试倒计时、资料库、作息健康、积分激励、成长报告，一个页面全搞定。

## 功能一览

| 模块 | 说明 |
|---|---|
| 🏠 首页仪表盘 | 按时段问候；目标进度横幅、考试倒计时条、今日任务进度环、今日专注时长、积分余额、今日课程、待复习；近 7 天专注趋势图；每日一条教育建议 |
| 🎯 目标管理 | 长期 / 学期 / 月 / 周目标，拆解为里程碑清单，进度条 + 截止倒计时，达成 +20 积分 |
| 📝 任务管理 | 按学科 / 来源 / 状态三维筛选，按日期分组；计划用时 vs 实际用时；专注计时器：倒计时、暂停 / 继续、完成 / 放弃，全局悬浮计时条，刷新不丢失 |
| ⏱️ 专注打卡 | 习惯 + 学科打卡计划，计时类 / 直接完成类；自定义番茄时长、休息时长、每轮个数；WebAudio 合成白噪音 / 粉噪音 / 棕噪音；睡眠记录 + 本周睡眠统计；一键添加运动打卡 |
| 📅 课程表 | 周视图 + 第几周显示；单周 / 双周课程（大学必备）；一键请假 / 销假；线上 / 线下、老师、地点、可回放、停课状态 |
| 🔁 复习中心 | 错题 / 单词 / 知识点 / 申论素材多类型；**SM-2 间隔重复算法**（记得越牢间隔越长，忘了回到第 1 天）；今日复习队列 + 自评打分 |
| 📝 自测组卷 | 录题（单选 / 多选 / 判断 / 填空），随机组卷、计时自测、自动判分、逐题解析，错题一键加入复习中心 |
| 🏆 考试倒计时 | 中考 / 高考 / 考研 / 国考等多考试管理，首页倒计时条 |
| 📚 资料库 | 网课 / 电子书 / 笔记链接收藏，按学科 / 类型筛选（只存链接与备注，不上传文件） |
| ⭐ 积分中心 | 积分规则、明细流水、奖励兑换（可自定义奖励） |
| 📈 成长报告 | 任务完成率、专注时长趋势、学科时间分布、自测正确率趋势、复习完成、积分趋势、12 周专注日历热力图；一键生成周报 / 月报文本并复制分享 |
| ⚙️ 设置 | 学段切换（小学～考公考编 7 大学段，学科体系自动适配）；场景模板一键应用（考研冲刺 / 考公备考 / 高考冲刺 / 大学期末周）；外观（浅色 / 深色 / 跟随系统）；数据导出 / 导入 / 清空 |

## 教育理念

- **目标 - 计划 - 执行 - 复习 - 复盘** 完整闭环
- **正向激励为主**：完成即时加分 + 鼓励语
- **番茄钟**专注法 + 间隔重复（SM-2）科学记忆
- **测试效应**：自测是最好的学习方法之一

## 使用说明

1. 用浏览器打开上方在线地址即可使用（手机 / 电脑均可，可安装为 PWA 离线使用）。
2. 数据保存在**本机浏览器**中，刷新、关闭都不丢失。
3. 换设备使用时：旧设备「设置 → 导出数据」得到 JSON 文件，新设备「设置 → 导入数据」即可衔接。
4. 首次打开内置演示数据：先去「设置」选择你的学段，或直接应用一个场景模板，再替换成自己的真实安排。

## 技术

- 原生 HTML / CSS / JavaScript，**零外部依赖**；PWA（manifest + Service Worker）支持离线与安装
- 数据经 localStorage 版本化持久化（`xuehang_db_v1`），支持版本迁移
- 响应式布局，桌面端优先，兼容手机宽度
